    Os mesmos testes aplicados a 2014, 2018 e 2022

            Estimativa de migração (regressão ecológica de Goodman)

            Para cada uma das 499.205 seções presentes nos dois turnos, os votos do 2º turno são explicados pela composição do 1º turno da mesma seção. Os coeficientes estimam “que fração de cada grupo do 1º turno foi para cada destino”. É a técnica clássica para o que a conversa queria — mas é ecológica: infere comportamento de grupos, não de indivíduos, e pode produzir valores fora de 0–100%.

                            Testes de dígitos

                            O último dígito das contagens de votos deveria ser uniforme (10% cada) se os números não foram inventados por humanos. A Lei de Benford (2º dígito) é muito citada, mas não se aplica bem a seções eleitorais porque elas têm tamanho limitado (~300 eleitores) — é mostrada apenas para comparação.

                            Último dígito — 2º turno

                            2º dígito × Lei de Benford — 2º turno

                            Os dois candidatos se desviam de Benford, na mesma direção — o esperado quando as seções têm tamanho limitado. Por isso este teste não serve como indicador de fraude aqui.
